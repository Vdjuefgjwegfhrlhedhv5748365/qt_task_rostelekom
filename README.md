# qt_task_rostelekom
Разработка приложения Qt на C++ и базы данных

Написать приложение на C++ с использованием графического
фреймворка Qt позволяющее добавлять примитивы и связи на графической
сцене. Примитивы задаются формой (эллипсы, прямоугольники,
многоугольники) и размерами. Связи между этими объектами задаются
динамически линиями. Создание примитивов происходит в процессе работы
приложения через элементы управления.

Каждый добавленный примитив должен идентифицироваться и
храниться в базе данных, информацию из базы данных отобразить
пользователю при помощи моделей (QSqlTableModel) и связей с
пользовательскими виджетами (QTableView), позволить пользователю
фильтровать отображаемые примитивы по критериям: номера фигур, типы
фигур, количество фигур. Физически данные из базы не должны удаляться,
изменяя только отображение в модели.

Реализовать возможность удаления выбранной фигуры из представления
(модели) и базы данных. После удаления одной из фигур все связи (линии)
должны автоматически удаляться.

В представлении пользователя реализовать отображение числа
элементов данного типа в виде делегата, по следующим правилам: если число
хранимых элементов от 1 до 3 рисовать один элемент фигуры (один
прямоугольник, эллипс или многоугольник в ячейке таблицы), если от 4 до 10 –
две иконки фигуры в соответствующей ячейке, если элементов более 10 – три
фигурки выбранного типа.

Данные которые должны храниться в базе данных: идентификатор
фигуры, тип фигуры, идентификаторы тех фигур с которыми связана данная,
общее количество фигур такого типа. В базовой версии используется драйвер
БД – SQLite.
